# Deliverables

Everything submitted or presented, by assignment. Each folder keeps its iterations beside
the submitted version, because this course marks process as well as outcome.

| Folder | Assignment | Status |
| --- | --- | --- |
| [`A1-introductory-pitch/`](A1-introductory-pitch/) | Introductory pitch | Submitted. Deck in `final/` |
| [`A2-design-proposal/`](A2-design-proposal/) | Design proposal | Submitted. The submitted copy still needs adding to `final/` |
| [`A3-final-submission/`](A3-final-submission/) | Design project: prototype, poster and documentation | Due Week 13 |

Inside each: `iterations/` holds working versions, `final/` holds what was handed in, and
`CHANGELOG.md` records what changed between them.

A3 takes the exported PDF of the Design Process Overview and Ethical Considerations wiki
pages, named `NO_PARKING_3DesignPrototype.pdf`, which goes in `A3-final-submission/final/`
once exported. The poster lives in [`design/`](../design/Team_12_Poster.pdf) and the
prototype in [`prototype/final/`](../prototype/final/) rather than being copied here.

## File naming

```
YYYY-MM-DD_vX.Y_short-description.ext
```

Bump the minor version for a working revision and the major version when something is
submitted. Never overwrite an older iteration.
