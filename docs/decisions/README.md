# Decision Records

Short numbered records of significant project decisions. When a tutor or marker asks *"why did you go that way?"*, the answer should already be written down here.

## When to write one

Write a record when a decision is hard to reverse, shapes work for more than one person, or would be hard to reconstruct later. Domain selection, concept convergence, scope cuts, a change of target audience, a technology choice.

Do **not** write one for routine choices. Meeting notes cover those.

## Format

Copy `0001-domain-selection.md` as the template. Number sequentially, never reuse a number, and use a slug that reads as the decision itself:

```
0001-domain-selection.md
0002-concept-convergence.md
0003-nostalgia-vs-reflective-framing.md
```

Each record carries a **Status** , `Proposed`, `Accepted`, or `Superseded by 000X`. Superseded records stay in place; we do not delete them. The trail matters more than the tidiness.
