# Docs

Working documents behind the project. Findings and write-ups live on the
[wiki](https://github.com/batinion/DECO_3500/wiki); this folder holds the records.

| Item | What is in it |
| --- | --- |
| [`charter/`](charter/) | Team charter, draft and signed |
| [`decisions/`](decisions/) | Numbered records of significant decisions and why we made them |
| [`AI-usage-log.md`](AI-usage-log.md) | Where and how AI tools were used in the project |

Research material (interviews, literature, competitor analysis) is in
[`research/`](../research/) at the top level, and testing evidence is in
[`user-testing/`](../user-testing/). Interview data is kept as de-identified responses
(participant codes only), in line with the consent we collected.

Ethical considerations are written up on the
[Ethical Considerations](https://github.com/batinion/DECO_3500/wiki/Ethical-Considerations)
wiki page rather than kept here, so the two can't drift apart.
