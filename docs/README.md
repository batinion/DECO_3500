# Docs

Working documents behind the project. Findings and write-ups live on the
[wiki](https://github.com/batinion/DECO_3500/wiki); this folder holds the source material
and the records.

| Folder | What is in it |
| --- | --- |
| [`charter/`](charter/) | Team charter, draft and signed |
| [`decisions/`](decisions/) | Numbered records of significant decisions and why we made them |
| [`research/`](research/) | Interview and competitor-analysis templates, and literature |

Interview findings themselves are written up on
[Research Findings](https://github.com/batinion/DECO_3500/wiki/Research-Findings) rather
than kept here as transcripts, in line with the consent we collected.
