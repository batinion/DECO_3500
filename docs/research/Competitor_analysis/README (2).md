# Competitor Analysis

A teardown of existing memory and time-capsule tools, done in the first phase (weeks 5–7) and presented in the team pitch. The goal was to find what already exists and where a group-focused tool would differ.

## Who we're designing for

**Groups with a shared endpoint:** uni cohorts, sports teams, workmates, school friend groups.

| Skills | Values | Workflows | Priorities |
|---|---|---|---|
| Phone-native. Already archive casually in camera rolls and group chats, but nobody owns the archive. | Shared history over solo reflection. The group's story matters more than a polished record. | Memory-keeping is spontaneous and scattered, only sorted out when storage runs out. | Low effort now, high payoff later. Wants a reason, and a date, to come back together. |

## What already exists

| Tool | Platform | What it does | Sealed until a date? | Group-authored? | Group-opened? |
|---|---|---|---|---|---|
| **OpenItLater** | Web only | Text messages that unlock on a set date | Yes | No | No |
| **Timecapsule.com** | Physical product | Physical keepsake capsules sold as gifts | Yes | No | No |
| **Capsuled** | App | Sealed photo and video capsules; no edits once sent | Yes | No | No |
| **PersonalCapsule** | iPhone | Private vault for letters, photos and voice notes | Yes | No | No |
| **Day One** | App | Journalling app with shared journals, but always open | No | Yes | Always open, nothing sealed |

## The gap

**Common pattern across all five:** a capsule is sealed until a date, then authored and opened by one person. The one tool that supports groups (Day One) has nothing sealed, so there is no moment of coming back together.

None of them combines:

1. **Group authorship:** everyone in the group contributes.
2. **Sealing:** nothing is visible until the set time.
3. **A shared reveal:** the group opens it together, as an event.

## How Space-Cap fills it

| Gap | Space-Cap |
|---|---|
| Single author | Every crew member submits prompted memories (photo, text, voice) |
| Opened alone | Reunion notification, then the crew opens the capsule together through a shared-control game and guess-who reveal |
| No reason to return | A set reveal date gives the group a reason, and a date, to reconnect |
| Group tools are always open | Submissions are anonymous and sealed until the reveal |
| Physical capsules don't travel | Digital, so it works for groups who disperse (e.g. international students) |

## Interview evidence that backs this up

See [`../interviews/thematic-analysis.md`](../interviews/thematic-analysis.md):

- **T5:** people rarely revisit memories unless something triggers it, so a scheduled reveal fills a real gap.
- **T6:** peers sit between "just for me" and "for the next generation", and no existing tool is built for them.
- **T4:** digital memories feel less deliberate than physical ones, which is why the rocket and capsule are framed as an object the group launches together.
